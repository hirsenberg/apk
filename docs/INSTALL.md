# 小米平板5安装与响铃验证

## 下载和安装

- 推荐：[下载 app-debug.apk](https://github.com/hirsenberg/apk/releases/download/v0.2.0/app-debug.apk)，或进入 [v0.2.0发布页](https://github.com/hirsenberg/apk/releases/tag/v0.2.0) 的 Assets 点击APK。
- Android提示时，允许当前浏览器／文件管理器“安装未知应用”。此权限给下载工具，不是给考研自习铃。
- 如果覆盖安装提示签名不一致，不要随意卸载（会清空课程数据），先确认安装包来源和签名。此版本是Debug调试版。

## 必开设置

1. 打开应用，进入“铃声与自动响铃设置”。
2. 点击“允许闹钟和提醒”，在系统页面允许精确闹钟；返回应用确认“已允许”。
3. 点击“允许通知”；若已拒绝，点“打开通知设置”，允许应用通知和“课程响铃”通知类别。
4. 小米系统：应用管理 → 考研自习铃 → 允许自启动／后台运行，省电策略选择“无限制”。不同MIUI版本入口文字可能略有差异，可用应用内“打开应用设置”“打开电池优化设置”按钮辅助找到入口。
5. 应用内铃声音量大于0；系统“闹钟音量”大于0。启用勿扰时，需要允许闹钟发声。
6. 点击“重新安排课程闹钟”，确认出现下次课程铃声时间。

## 立即验证

点击“一分钟后测试响铃”，确认显示具体测试时间；返回桌面并锁屏，约一分钟后应播放上课铃并短暂显示播放通知。需要停止时点击通知的“停止”。测试和正常课程安排相互独立，再点测试只替换上一次测试。

若未响：先重新打开应用查看设置页“最近状态”，核对精确闹钟、自启动、无限制省电、通知、系统闹钟音量和应用滑块，再重新测试。不要使用系统“强行停止”；被强行停止后Android不会再投递闹钟，需重新打开应用。

## 运行方式和限制

- 无需联网，无需常亮屏幕，短音效播放结束即释放前台服务与唤醒锁。
- 开机后需要先完成首次解锁，才能读取加密存储内的Room课表并恢复安排。
- 系统时间／时区修改后会重排，但课表仍按默认Asia/Shanghai解释，不自动跟随设备切换课表时区。
- 不重放超过两分钟的过期闹钟。0%为主动静音，勿扰和系统闹钟音量也可能让播放无声。
- 云端已验证编译、APK签名和音频打包，没有连接实体小米平板；MIUI锁屏实际表现请用一分钟测试确认。
